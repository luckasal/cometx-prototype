| Feedback | Current state in this branch | Remaining boundary |
| --- | --- | --- |
| Ticket and membership connection is confusing | Event ticket editor explains required, discount and free entitlements and reads the active plans' assigned benefits. | Entitlement definitions and plan assignments still cannot be edited in Back Office. A guarded media browser component exists in code but is no longer offered in this simplified editor. | Migrations `0018_event_media_storage.sql` and `0019_event_owned_speakers.sql` must be applied with the app release; hosted upload acceptance remains pending. Removing a reference does not delete its stored file. |
| Speakers rarely repeat | Speakers can be drafted inside the event editor and are only inserted when event save reaches speaker association. One-off rows are tagged with their owning event, editable/deletable in that event, and excluded from the general reusable-speaker list. | The existing `speakers` table is reused with nullable `event_id`; it is event-owned behavior rather than a separate table. Workshop references block deletion until detached. Hosted migration and CRUD acceptance remain pending. |
| Staff roles | Admin, Event manager, Data analyst and Marketing capabilities, assignment controls, and server guards are deployed to the prototype. | Restricted-role signed-in allowed/denied tests still need designated test accounts. Do not describe that acceptance as complete. |
